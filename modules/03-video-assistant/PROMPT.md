# Промпт для эфира

Вставляется в тот же чат, где собирали сайт: агент возьмёт оттуда услуги, цены и адрес сайта.
Ключи берутся из общего `.env` репозитория — в промпте их нет.

```text
Сайт готов. Теперь поставим на него видеоконсультанта — кнопку, по
которой посетитель попадает в живой видеозвонок с AI-аватаром: тот
отвечает на вопросы, снимает возражения и доводит до записи.

Модуль: https://github.com/skipaoff/VLAD_WEBINAR/tree/main/modules/03-video-assistant

Забери репозиторий, перейди в папку modules/03-video-assistant, открой
CLAUDE.md и работай строго по нему. Коротко, что там:

1. Спроси у меня одним сообщением три вещи: бренд и имя ассистента,
   нишу и цель звонка, тон общения. Услуги, цены, адрес и часы возьми
   с сайта, который мы только что сделали.

2. Заполни business/brand.json. Домен нашего сайта впиши в
   allowed_origins до создания профиля — иначе кнопка на сайте
   не загрузится.

3. Заполни знания в business/kb, цели и ограничения в config.

4. Прогони npm test и npm run verify. Красное — не иди дальше.

5. Создай профиль: npm run tavus:setup.

6. Поставь кнопку на сайт по web/install/README.md, задеплой и дай
   ссылку. Я позвоню сам.
```

## Что происходит на экране

1. Агент задаёт три вопроса и заполняет модуль данными с сайта.
2. Проверки проходят зелёным.
3. Setup создаёт аватара, цели, ограничения и кнопку — в терминале видны шаги.
4. На сайте появляется кнопка. Ведущий нажимает её в кадре и разговаривает с аватаром вживую.
