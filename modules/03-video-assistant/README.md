# Видеоконсультант на сайт

Кнопка на сайте, по которой посетитель попадает в видеозвонок с AI-консультантом. Аватар видит,
слышит и отвечает голосом и лицом, задержка меньше, чем у обычного голосового бота. Консультант
знает услуги и цены бизнеса, отвечает на вопросы, снимает возражения и, если человек согласен,
забирает контакт.

Работает на сервисе Tavus: он держит видеосвязь, аватара и защищённую кнопку. Своего сервера
для звонков не нужно.

## Как устроено

```
business/
  brand.json        бренд, имя ассистента, язык, цель звонка, домен сайта
  kb/               роль, услуги, цены, правила — четыре файла по порядку
config/
  tavus.json        лицо аватара, второй язык, названия профиля и кнопки
  languages.json    готовые языки: предупреждение «я AI» и надписи кнопки
  objectives.json   чего должен добиться звонок
  guardrails.json   чего ассистент не делает
src/                сборка промпта и работа с API
scripts/            проверка, создание профиля, замена лица, демо-страница
web/                рецепты установки кнопки: HTML, React, Next.js
demo/               страница для первого звонка
test/               проверки конфигурации
```

Поменять бизнес — значит заполнить `business/` и `config/`, код не трогается.

## Язык

Язык задаётся один раз — полем `language` в `business/brand.json`, кодом ISO 639-1: `ru`, `uk`,
`en`, при необходимости с регионом (`pt-br`). Оттуда он расходится сам:

- в промпт — указанием говорить на этом языке и не переходить на другой без просьбы;
- в профиль Tavus — списком языков разговора;
- в кнопку на сайте — надписями на ней и на экранах проверки камеры и конца звонка.

Готовые языки лежат в `config/languages.json` — русский, украинский и английский. Нужен другой:
добавьте блок по образцу соседнего, иначе проверка остановит на незнакомом коде. Знания в
`business/kb/` пишутся на том же языке — их переводит тот, кто заполняет модуль.

Если посетители пишут на двух языках, второй впишите в `extra_languages` в `config/tavus.json`.
Разговор всё равно ведётся на основном, но речь на втором аватар разберёт.

## Что нужно

- Node.js 20 и новее.
- Ключ Tavus — в общем `.env` в корне репозитория (или в `.env` модуля), по образцу `.env.example`. Ключ живёт только на
  машине, где создаётся профиль, на сайт не попадает.

## Как запустить

```bash
npm test
npm run verify
npm run tavus:setup
npm run demo
```

Демо открывается на `http://localhost:4173` — кнопка справа внизу.

Setup выдаёт **Deployment ID** — это единственное, что ставится на сайт. Установка кнопки —
по таблице в [web/install/README.md](web/install/README.md).

## Свой аватар

В PAL Maker на maker.tavus.io создаётся лицо из видео или фото. Из видео получается лучше и
с копией голоса: нужен один ролик — полминуты естественной речи и полминуты неподвижного взгляда
в камеру. Когда появится `face_id`:

```bash
npm run tavus:set-face -- ВАШ_FACE_ID
```

Меняется только лицо, всё остальное остаётся.

## Перед публичным запуском

В PAL Maker включите: разрешённые домены, дневной и общий лимит разговоров, максимальную
длительность, защиту от ботов. Иначе чужой сайт или бот сожжёт минуты.

## Подпись «Powered by Tavus»

Её показывает сама кнопка, и решает это сервис по настройкам аккаунта — флаг приходит в кнопку с
сервера. Из кода сайта подпись не убирается, и прятать её стилями внутри кнопки не стоит:
это обход условий сервиса. Убрать её можно только настройкой аккаунта Tavus.

## Проверки

`npm test` следит, чтобы в конфигурации не осталось незаполненных полей, переходы между целями
были корректны, у ассистента было одно имя на весь промпт, язык был заполнен известным кодом,
а ключ читался из `.env`, а не из командной строки. `npm run verify` ищет в файлах строки, похожие на ключ.
