# Инструкция агенту: поставить на сайт видеоконсультанта

Тебя попросили поставить на сайт видеоконсультанта. Это не голосовой бот, а живой видеозвонок:
посетитель нажимает кнопку и разговаривает с AI-аватаром, который видит, слышит и отвечает.

Сайт уже собран раньше в этом же чате. Модуль рабочий, но пустой под бизнес: его нужно
заполнить и подключить. Работает на сервисе Tavus — он держит видеосвязь и аватара.

## Шаг 1. Спроси четыре вещи — одним сообщением

Только это, и жди ответа:

1. Название бренда и как представляется ассистент.
2. Чем занимается бизнес и какая главная цель звонка.
3. Каким должен быть тон общения.
4. На каком языке говорит ассистент.

Услуги, цены, адрес, часы работы и контакты бери с сайта сам. Не выдумывай того, чего там нет.

## Шаг 2. Заполни бизнес

`business/brand.json` — первым, из него собирается всё остальное. Полный пример полей —
`business/brand.example.json`.

Обязательно:

- `website_url` — адрес сайта из этого чата;
- `allowed_origins` — домен этого сайта, например `https://comfort-dental.vercel.app`.
  **Домен должен быть здесь до создания профиля**: он записывается в развёртывание при
  setup, и на сайте, которого нет в списке, кнопка не загрузится. `localhost` оставь для
  проверки.

Имя ассистента пишется только здесь, в `assistant_name`. В файлах знаний его не повторяй —
иначе модель получит два разных имени.

Язык тоже задаётся только здесь, в `language` — кодом ISO 639-1: `ru`, `uk`, `en`, при
необходимости с регионом (`pt-br`). Из этого поля язык расходится сам: в промпт, в профиль
Tavus и в надписи кнопки. Код должен быть описан в `config/languages.json`; если нужного языка
там нет, добавь блок по образцу соседнего — иначе проверка не пропустит.

Если посетители пишут на двух языках, второй впиши в `extra_languages` в `config/tavus.json`:
разговор всё равно ведётся на основном, но речь на втором аватар разберёт.

## Шаг 3. Знания

Четыре файла в `business/kb/`, порядок не менять. **Пиши их на языке из `language`** — если
он не русский, переведи и заготовки, которые лежат в папке:

| Файл | Что в нём |
|---|---|
| `01-identity.md` | роль и стиль — без имени |
| `02-services.md` | услуги с сайта |
| `03-pricing.md` | цены — только реальные |
| `04-rules.md` | ограничения, идёт последним |

## Шаг 4. Цели и ограничения

- `config/objectives.json` — чего должен добиться звонок. Контакт собирается только после
  согласия посетителя.
- `config/guardrails.json` — чего ассистент не делает.
- `config/tavus.json` — лицо, названия профиля и развёртывания под этот бренд, второй язык.
  Пустой `face_id` — setup выберет готовое лицо сам.
- `config/languages.json` — готовые блоки языков: как звучит предупреждение «я AI» и что
  написано на кнопке и экранах звонка. Трогать нужно, только если добавляешь новый язык.

## Шаг 5. Проверка

```bash
npm test
npm run verify
```

Обе команды должны пройти. Красная — не создавай профиль, сначала исправь.

## Шаг 6. Создай профиль

Ключи модуль находит сам, по порядку: `.env` модуля → общий `.env` в корне репозитория →
`~/.config/vlad-webinar/.env`. Не рассказывай об этом в чате и не спрашивай ключи заранее.
Репозиторий уже есть на машине — работай в нём, заново не клонируй.

Команда сказала «Не задан TAVUS_API_KEY» — только тогда попроси вписать его в общий `.env`
в корне репозитория. **Ключ в чат не принимай и в терминале не печатай.**

```bash
npm run tavus:setup
```

Setup создаёт аватара, цели, ограничения и развёртывание кнопки, переводит надписи кнопки
на язык бизнеса и выдаёт **Deployment ID**.
Повторный запуск остановится, если профиль уже есть, — так не плодятся платные дубли.

## Шаг 7. Поставь кнопку на сайт

По таблице в `web/install/README.md`: статика, React или Next.js. На сайт уходит только
Deployment ID — он безопасен. Ключ на сайт не попадает никогда.

Задеплой сайт и скажи человеку одним сообщением: кнопка стоит, можно звонить.

## Подпись «Powered by Tavus»

Её рисует сама кнопка Tavus, и показывать её или нет — решает сервис по настройкам аккаунта:
кнопка получает этот флаг с сервера при загрузке. Из кода сайта её не убрать.

Не прячь её стилями и скриптами внутри кнопки: это обход условий сервиса и сломается при
первом обновлении. Если нужно без подписи — это настройка аккаунта Tavus, её делает владелец.

## Чего не делать

- Не записывать `TAVUS_API_KEY` в файлы, код сайта, `NEXT_PUBLIC_*` и `VITE_*`.
- Не создавать профиль повторно, если `.tavus/state.json` уже есть.
- Не держать одну память на всех посетителей: для анонимных она выключена.
- Не выдумывать цены, услуги и сроки.
