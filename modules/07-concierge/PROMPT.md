# Промпт для эфира

Ведущий копирует это кнопкой на пульте, в тот же чат, где собирали сайт и рекламу.

```text
Мы собрали клиенту всё: сайт, ассистента, креативы, рекламу и продавца.
Теперь покажем, что это можно продавать не по одному, а сразу десятерым.

Модуль: https://github.com/skipaoff/VLAD_WEBINAR/tree/main/modules/07-concierge

Забери репозиторий, открой modules/07-concierge/CLAUDE.md и делай строго
по нему. Коротко, что там:

1. Проверь доступ к аккаунту: python concierge.py check
   Не авторизован — скажи мне, я войду сам. Ключ модели не проси,
   его тут нет: писать будешь ты, в этом чате.

2. Заполни knowledge/what-we-offer из того, что мы уже сделали:
   что предлагаем, ссылка на собранный сайт как доказательство, цена.

3. Посмотри лидов: python concierge.py leads
   Это список, который я дал. Сам никого не ищи и не добавляй.

4. На каждого напиши своё сообщение — по правилам из
   knowledge/how-to-write/01-first-message.md. Конкретная деталь про
   его бизнес, что с этим можно сделать, лёгкий вопрос. Три-четыре
   строки, без ссылок и без цен. Одинаковых текстов быть не должно.
   Каждое клади в очередь: concierge.py queue --to @кто --text "…"

5. Покажи мне план: python concierge.py drain
   Я посмотрю и скажу «ок». Без этого не отправляй.

6. После «ок»: python concierge.py drain --confirm — в фоне.
   Уходит по одному, с паузами в несколько минут.

7. Пока идёт — проверяй ответы: python concierge.py inbox
   На каждый отвечай сам, по knowledge/how-to-write/02-objections.md.
   Кто-то просит не писать — вычёркивай сразу.

8. Прозвучало «давайте» или «сколько» — зови меня, дальше я сам.

Это не рассылка: десять сообщений, каждое своё, с паузами. Лимиты в коде
не трогай.
```

## Что происходит дальше

1. Агент читает список лидов и то, что мы сделали для клиента.
2. Пишет десять разных сообщений и показывает их одним планом.
3. После «ок» отправляет по одному, с паузами — примерно полчаса на десять.
4. Ответы разбирает сам, сделки отдаёт ведущему.

В эфире это последний кадр: на экране очередь из десяти живых сообщений, каждое про
конкретный бизнес, и первые ответы приходят прямо во время разговора.
