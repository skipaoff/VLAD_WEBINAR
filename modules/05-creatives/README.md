# Модуль 05 — база креативов

Не скрипт и не универсальный генератор, а готовая база промптов. Каждый промпт — конкретный
пост с подписью, что получится на выходе. Ведущий смотрит список, называет четыре-шесть номеров,
и агент рисует их через Higgsfield прямо в эфире.

Ничего не придумывается на ходу: композиция, свет, палитра и типографика уже прописаны и
проверены. Меняется только бренд, язык надписи и имена — остальное повторяется от бизнеса
к бизнесу.

команда. Например 01, 03, 04, 06, 09.

## Язык надписи

Текст на картинке по умолчанию **английский** — он одинаково хорошо рисуется любой моделью и
не разваливается на кириллице. Если бизнес говорит на другом языке, в каждом промпте внизу лежит
готовая строка на замену. Украинский подготовлен, остальные языки агент переводит сам, сохраняя
длину строк — иначе поедет вёрстка.

Имена, названия и бренды не переводятся никогда.

## Чем рисуем

`nano_banana_pro` — он умеет 4:5 и лучше остальных держит текст на картинке.
Одна картинка в 2k стоит 2 кредита.

```bash
higgsfield generate create nano_banana_pro \
  --prompt "$(cat creatives/06.prompt.txt)" \
  --aspect-ratio 4:5 --resolution 2k --wait
```

`gpt_image_2` для этих постов не подходит: у него нет соотношения 4:5, максимум 3:4 — пост
придётся обрезать.

## Как добавить свою нишу

Скопируй `prompts/dental/` в папку с названием ниши и перепиши промпты, сохранив структуру
файла: заголовок, что на выходе, текст на картинке, сам промпт, таблица языков. Структура важнее
содержания — по ней агент собирает список для ведущего.
