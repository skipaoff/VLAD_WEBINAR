# Что ломается и что с этим делать

Facebook отвечает ошибкой в JSON: `error.message`, `error.code`, иногда `error_user_msg`.
Показывай человеку `error_user_msg`, если он есть, — там понятный текст. Молча обходить
ошибку нельзя.

| Что видишь | Что на самом деле | Что делать |
|---|---|---|
| `(#100) special_ad_categories` | не передан обязательный параметр | добавь `special_ad_categories=[]` |
| `(#200) Requires ads_management permission` | у токена нет прав | перевыпустить токен с `ads_management` |
| `Invalid appsecret_proof` | подпись не совпала | пересчитай подпись именно от текущего токена |
| `(#190) Session has expired` | токен протух | новый токен, для долгой работы — System User |
| `(#294) Managing advertisements requires...` | приложение не прошло проверку или нет доступа к кабинету | проверить доступ пользователя к кабинету в Business Manager |
| `The page is not associated...` | страница не привязана к кабинету | привязать страницу или взять другую из `/me/accounts` |
| `Ad account has no funding source` | нет платёжки | добавить карту в кабинет, иначе кампания не запустится |
| `(#1885183) ...ad account is disabled` | кабинет отключён | этот кабинет использовать нельзя |
| `Invalid parameter` на targeting | битый JSON или неверный ключ города | проверь ключ через поиск гео |
| `budget too low` | бюджет ниже минимума валюты | подними бюджет или проверь порядок: сумма в мелких единицах |
| креатив отклонён модерацией | текст или картинка нарушают правила | читай причину, чини текст, картинку не трогай |

## Про версию API

Если ответ говорит, что версия больше не поддерживается — подними `META_API_VERSION`
до той, которую Facebook называет в ошибке, и повтори. Версия вынесена в `.env` именно
для этого.

## Чего не делать при ошибке

- Не повторять тот же запрос по кругу.
- Не создавать вторую кампанию, потому что первая не получилась.
- Не просить токен в чат: он уже есть в `.env`, а если не работает — это чинит человек.
- Не выключать проверки, чтобы «прошло».
