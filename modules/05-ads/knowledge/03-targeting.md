# Кому показываем

## Гео

Локальному бизнесу — город с радиусом, не страна.

```json
"geo_locations": {
  "cities": [{"key": "<ключ из поиска>", "radius": 15, "distance_unit": "kilometer"}]
}
```

Радиус 10–20 км для клиники, салона, детейлинга: дальше человек не поедет. Для города-
миллионника хватит 10, для небольшого — 25.

Ключ города берётся поиском (`01-api.md`), а не из головы.

## Возраст и пол

Из данных бизнеса. Нет данных — 25–55 и оба пола, и скажи об этом вслух.

Каждое лишнее сужение режет аудиторию и поднимает цену клика. Пол сужай только когда услуга
действительно женская или мужская, а не «нам кажется».

## Интересы

Бери 3–7 штук с понятными названиями. Кладутся в `flexible_spec`, внутри группы работают
как «или»:

```json
"flexible_spec": [{"interests": [{"id": "6003...", "name": "Dentistry"}]}]
```

Смотри на размер аудитории после сужения по гео:

| Охват | Что делать |
|---|---|
| меньше 50 тыс. | слишком узко, убери часть интересов |
| 50–500 тыс. | нормально для города |
| 500 тыс. – 2 млн | оптимально |
| больше 5 млн в одном городе | что-то не так с гео, проверь ключ |

В маленьком городе интересы часто вообще лишние: гео плюс возраст уже дают нужный размер.
Не добавляй интересы ради того, чтобы они были.

## Advantage+ аудитория

```json
"targeting_automation": {"advantage_audience": 1}
```

На локальном гео и небольшом бюджете помогает чаще, чем мешает: Facebook расширит аудиторию,
если заданная слишком узкая. Включай по умолчанию, если человек не просил иначе.

## Исключения

Для локального бизнеса обычно не нужны. Не усложняй структуру ради красоты.

## Готовый блок таргетинга

```json
{
  "geo_locations": {"cities": [{"key": "KEY", "radius": 15, "distance_unit": "kilometer"}]},
  "age_min": 25,
  "age_max": 55,
  "flexible_spec": [{"interests": [{"id": "ID", "name": "NAME"}]}],
  "targeting_automation": {"advantage_audience": 1},
  "publisher_platforms": ["facebook", "instagram"],
  "facebook_positions": ["story"],
  "instagram_positions": ["story", "reels"],
  "device_platforms": ["mobile"]
}
```
