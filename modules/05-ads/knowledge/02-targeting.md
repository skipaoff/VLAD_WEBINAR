# Кому показываем

## Гео

Локальному бизнесу — город плюс радиус, а не вся страна.

```python
"geo_locations": {
    "cities": [{"key": "<id города>", "radius": 15, "distance_unit": "kilometer"}]
}
```

Ключ города ищется через `search_geo_locations(query="Kyiv", location_types=["city"])`.
Не подставляй id наугад: неверный ключ либо отвалится ошибкой, либо покажет рекламу не там.

Для клиники, салона, детейлинга радиус 10–20 км. Дальше человек не поедет.

## Возраст и пол

Из брифа бизнеса. Если данных нет — 25–55, оба пола, и скажи об этом человеку вслух.
Не сужай без причины: каждое лишнее условие режет аудиторию и поднимает цену.

## Интересы

```python
interests = search_interests(query="dentistry", limit=25)
```

Бери 3–7 штук с понятными названиями и большой аудиторией. Смотри на `audience_size`:
меньше 100 000 в узком гео — группа задохнётся.

Интересы кладутся в `flexible_spec` — внутри одной группы они работают как «или».

```python
"flexible_spec": [{"interests": [{"id": "...", "name": "..."}]}]
```

## Advantage+ аудитория

```python
"targeting_automation": {"advantage_audience": 1}
```

На маленьком гео и маленьком бюджете это чаще помогает, чем мешает: Facebook сам расширит
аудиторию, если заданная слишком узкая. Включай по умолчанию, если человек не просил иначе.

## Сколько групп делать

Одна. На старте с бюджетом $10–30 в день вторая группа только делит деньги.
Вторую добавляют, когда первая набрала данные — это уже не про эфир.
