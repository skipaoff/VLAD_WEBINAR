# Инструкция агенту: настроить и запустить рекламу

Тебя попросили запустить рекламу на сайт и дали ссылку на этот модуль. Креативы уже сделаны
на прошлом шаге и лежат в `creatives/` — ты видел их в этом же чате.

Кабинет боевой. Реклама запускается по-настоящему, за настоящие деньги. Поэтому есть два
обязательных подтверждения: перед созданием и перед запуском. Прочитай `knowledge/06-safety.md`
до того, как что-то делать.

MCP-сервера нет. В Facebook ходишь напрямую — как, написано в `knowledge/01-api.md`.

## Шаг 1. Онбординг: получи доступ

Проверь, есть ли рядом `.env` с ключами.

**Если файла нет** — попроси одним сообщением ровно три вещи и объясни, где их взять:

```
Для запуска нужен доступ к кабинету. Три значения:

1. ID рекламного кабинета — вида act_123456789
   Ads Manager → Настройки аккаунта, или в адресной строке после act=

2. Access Token с правами ads_management и ads_read
   developers.facebook.com → твоё приложение → Marketing API → Tools

3. App Secret приложения
   developers.facebook.com → Settings → Basic → App Secret

Положи их в .env рядом с модулем — образец в .env.example.
В чат не пиши, я прочитаю из файла.
```

Ключи в чат не принимай и в свои сообщения не копируй. Если человек всё же прислал их
текстом — скажи, что положишь в `.env`, и больше нигде их не повторяй.

**Если файл есть** — сразу проверь, что доступ живой, тремя запросами из `01-api.md`:
отладка токена, права, список кабинетов. Убедись, что `account_status` равен `1`.

Не получилось — скажи, что именно ответил Facebook, и остановись. Дальше идти бессмысленно.

## Шаг 2. Собери данные

Заполни `account.json`. Часть берётся из API, часть с сайта, и только остаток спрашивается.

| Поле | Откуда |
|---|---|
| `currency`, `timezone` | из `/me/adaccounts` |
| `page_id`, `instagram_id` | из `/me/accounts` |
| `business_name`, `site_url`, `city`, `language` | с сайта, который делали на прошлых шагах |
| `city_key` | поиском гео по названию города |
| `age_min`, `age_max`, `genders`, `audience_notes` | из данных бизнеса; нет — ставь 25–55, оба пола |
| `daily_budget` | спроси, если человек не назвал |

Спрашивай одним сообщением и только то, чего действительно нет.

## Шаг 3. Прочитай базу знаний

Семь файлов в `knowledge/`, по порядку. В них решено, что и как делать:

1. `01-api.md` — все вызовы Facebook с подписью и примерами.
2. `02-structure.md` — структура, цель, бюджет, плейсменты.
3. `03-targeting.md` — гео, возраст, интересы, размеры аудитории.
4. `04-copy.md` — как писать тексты и что снимает модерация.
5. `05-naming.md` — как называть.
6. `06-safety.md` — два подтверждения и границы.
7. `07-errors.md` — что означают ошибки Facebook.

Своих решений поверх них не изобретай.

## Шаг 4. Посмотри креативы и напиши тексты

Открой картинки из `creatives/`. По каждой определи, про что она: услуга, возражение,
настроение, знакомство с врачом. Под каждую напиши свой текст по формуле из `04-copy.md` —
на языке сайта.

## Шаг 5. Подбери аудиторию и покажи план

Найди ключ города, подбери интересы, собери блок таргетинга, запроси оценку охвата.

Покажи план по форме из `06-safety.md` и **жди «ок»**. Ничего не создавай раньше.

## Шаг 6. Создай

После «ок» — по порядку из `01-api.md`: картинки, кампания, группа, креативы, объявления.
Всё в статусе `PAUSED`.

Сохраняй ID каждого созданного объекта — они понадобятся для запуска и для лога.

## Шаг 7. Покажи таблицу и жди второго «ок»

Что создано, с какими ID, ссылка на кампанию в Ads Manager. И строка, сколько открутится
за первые сутки.

Жди. Не включай.

## Шаг 8. Запусти

После второго «ок» переведи в `ACTIVE` объявление, группу и кампанию — именно в этом порядке.
Включить только кампанию мало, показов не будет.

Проверь статусы обратным запросом и скажи человеку:

- что реклама включена;
- ссылку на кампанию;
- что первые показы пойдут через 15–30 минут, а судить о цене клика раньше двух-трёх дней
  бессмысленно.

Запиши лог в `history/ГГГГ-ММ-ДД.md`.

## Чего не делать

- Не создавать и не включать ничего без «ок». Два раза, каждый отдельно.
- Не трогать кампании, которые были в кабинете до тебя.
- Не удалять ничего.
- Не просить ключи в чат и не повторять их в сообщениях.
- Не обещать результат в тексте объявления.
- Не оптимизировать кампанию после запуска — это не задача этого модуля.
