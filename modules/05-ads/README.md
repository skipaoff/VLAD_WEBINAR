# Модуль 05 — запуск рекламы

Агент берёт готовые креативы из предыдущего шага, пишет под каждый текст, подбирает гео и
аудиторию, собирает кампанию в боевом кабинете, показывает её на утверждение и запускает.

Собран из [ai-target-agent](https://github.com/skipaoff/ai-target-agent) — взята та часть,
что отвечает за настройку и запуск. Оптимизация, отчёты и дашборд остались в исходном
репозитории: задача этого модуля — запустить правильно, а не вести кампанию дальше.

## Чем отличается от исходного агента

| | ai-target-agent | этот модуль |
|---|---|---|
| Доступ к Facebook | через MCP-сервер | напрямую по ключам |
| Задача | вести кабинет постоянно | один правильный запуск |
| Оптимизация, отчёты | есть | нет |
| Онбординг | опросник на 8 шагов | три ключа и данные с готового сайта |

MCP убран намеренно: в эфире не должно быть шага «поставь сервер, пропиши конфиг,
перезапусти Claude». Ключи дают полный доступ, и этого достаточно.

## Из чего состоит

```
.env.example        три ключа доступа — заполняются на месте
account.json        данные кабинета и аудитории
knowledge/          семь файлов, по которым агент принимает решения
history/            лог того, что и когда было запущено
CLAUDE.md           сценарий для агента
PROMPT.md           промпт, который копирует ведущий
```

## Что решено заранее

- **Цель — трафик.** Пикселя на сайте нет, поэтому оптимизация на конверсии невозможна:
  Facebook нечего считать. Заявки собирают голосовой ассистент и продавец, поставленные
  на прошлых шагах, — это честная связка.
- **Одна кампания, одна группа.** На бюджете 10–30 в день вторая группа делит деньги.
- **Гео — город с радиусом**, не страна.
- **Плейсменты под формат картинки.** Креативы 9:16 — значит Stories и Reels.
- **Два подтверждения.** Одно перед созданием, второе перед включением. Кабинет боевой.

## Что нужно заранее

Три значения — ID кабинета, Access Token, App Secret. Как их получить, написано в
[SETUP.md](SETUP.md). Если их нет к началу эфира, агент попросит их сам первым сообщением.

Плюс сам кабинет: страница Facebook привязана, платёжка добавлена, `account_status` равен
единице. Без платёжки кампания создастся, но не запустится.

## Проверка перед эфиром

```bash
cd modules/05-ads && python3 -m pytest -q tests
```

На чистом шаблоне красный — в `account.json` стоят метки. Зеленеет, когда данные кабинета
вписаны, база знаний на месте и в репозиторий не попал ключ.
