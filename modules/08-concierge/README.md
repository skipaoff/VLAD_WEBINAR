# Модуль 08 — консьерж

Пишет первым тем, кого ты сам выбрал, и ведёт с ними переписку, пока ты смотришь.
Не бот и не рассылка: сообщения уходят с живого аккаунта, каждое написано под
конкретный бизнес.

Собран из [tg-sales-agent](https://github.com/skipaoff/tg-sales-agent) — оттуда взято
разделение на слои и работа с живым аккаунтом. Вариант с ботом убран: бот не может
написать первым, а вся задача здесь именно в этом.

## Мозги снаружи

У модуля **нет ключа Anthropic и нет своей модели**. Тексты пишет Claude Code, в котором
ты работаешь: он читает знания, смотрит на лид и складывает готовое сообщение в очередь.
`concierge.py` только отправляет — по одному, с паузами, и следит за лимитами.

Так сделано не из экономии. Массовая рассылка одинакового текста — это то, за что
блокируют аккаунты. Когда каждое сообщение пишется отдельно живой моделью под конкретный
бизнес, поведение не отличается от обычной переписки.

## Из чего состоит

```
concierge.py         руки: отправить, выждать, показать ответы, остановиться
config.json          лимиты и темп
leads.csv            кому пишем — заполняет владелец, потолок 20
.env                 TG_API_ID и TG_API_HASH, больше ничего

knowledge/
  what-we-offer/     что предлагаем, чем доказываем, сколько стоит — заполняет владелец
  how-to-write/      как писать первым, что отвечать, чего нельзя — уже написано

state/               кому написали, кто ответил, кто вычеркнут
```

Код в `knowledge/` не заглядывает. Туда смотрит Claude.

## Команды

| | |
|---|---|
| `login` | разовая авторизация аккаунта |
| `check` | кто я, сколько лидов, что в очереди, сколько осталось на сегодня |
| `leads` | список и статусы |
| `queue --to @user --text "…"` | положить сообщение в очередь |
| `drain` | показать план; `--confirm` — отправить |
| `inbox` | новые ответы с прошлой проверки |
| `reply --to @user --text "…"` | ответить одному |
| `stop --to @user` | вычеркнуть навсегда |

## Что зашито в код, а не в просьбу

- **Потолок двадцать лидов.** Больше скрипт не примет из `leads.csv`.
- **Десять сообщений за прогон, двадцать в сутки.**
- **Паузы 90–300 секунд**, длинная пауза 15 минут каждые пять сообщений.
- **Два одинаковых текста в очередь не попадут.**
- **Повторно тому же человеку не напишем.**
- **Стоп-слова.** «Не пишите», «отпишитесь», «спам» — статус `stopped` и больше ни одного
  сообщения.
- **Ограничение от Telegram останавливает прогон целиком**, а не «пропустим этого».

## Честно про риск

Telegram ограничивает аккаунты за сообщения незнакомым — это правда, и никакие паузы
не дают гарантии. Поэтому:

- используй **отдельный рабочий аккаунт**, не тот, где переписка с семьёй;
- аккаунт должен быть живой: с историей, аватаркой, не вчера созданный;
- десять сообщений в день — это потолок, а не цель;
- получил ограничение — остановись на сутки, а не иди с другого номера.
