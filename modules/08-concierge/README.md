# Консьерж

Пишет первым тем, кого ты выбрал, и ведёт с ними переписку. Сообщения уходят с твоего
рабочего аккаунта Telegram — обычная личка, без пометки «бот». Каждое письмо пишется
отдельно под конкретный бизнес и отправляется по одному, с паузами.

Задача модуля — превратить список из десяти-двадцати найденных бизнесов в живые диалоги:
написать, ответить на первые вопросы и передать тебе тех, кто заинтересовался.

## Как устроено

Три части, каждая занимается своим:

```
concierge.py     отправка: очередь, паузы, лимиты, входящие
knowledge/       что говорить: предложение и правила переписки
leads.csv        кому писать
```

Тексты сообщений пишет Claude Code, в котором ты работаешь: он читает `knowledge/`,
смотрит на конкретный лид и кладёт готовое письмо в очередь. `concierge.py` забирает
очередь и отправляет — по одному, выдерживая паузы и следя за лимитами.

Поэтому каждое сообщение получается своим: под бизнес, к которому обращаются. Десять
одинаковых писем, разосланных подряд, — это то, за что Telegram ограничивает аккаунты;
здесь такого не происходит по устройству, а не по договорённости.

```
leads.csv ──► Claude пишет письмо ──► очередь ──► отправка с паузами
                     ▲                                    │
                     └──────── ответы клиентов ◄───────────┘
```

## Что тебе понадобится

Три вещи, все бесплатные. Пятнадцать минут, если делаешь первый раз.

### 1. Отдельный аккаунт Telegram

**Не личный.** Консьерж пишет от имени того аккаунта, который ты подключишь, — и если
что-то пойдёт не так, ограничение прилетит именно на него.

Каким должен быть аккаунт:

- заведён не вчера: свежие номера ловят ограничение на третьем сообщении;
- с аватаркой, именем и хоть какой-то историей переписки;
- лучше на отдельной симке, а не на основном номере.

Пустой аккаунт, созданный ради рассылки, Telegram вычисляет за день. Живой рабочий
аккаунт, с которого ты и так общаешься по делу, — нормально.

### 2. Два значения с my.telegram.org

Это официальный доступ к API Telegram, его выдают всем и бесплатно.

1. Открой **my.telegram.org** и войди по номеру того аккаунта, с которого будешь писать.
   Код придёт в само приложение Telegram, не в SMS.
2. Выбери **API development tools**.
3. Заполни форму: название приложения и короткое имя — любые, например `concierge`.
   Платформа — **Desktop**, URL можно оставить пустым.
4. После сохранения появятся два значения: **App api_id** (число) и **App api_hash**
   (длинная строка). Это они и нужны.

Форма выдаётся один раз на аккаунт. Потерял значения — они остались на той же странице,
просто зайди снова.

Положи их рядом с модулем:

```bash
cd modules/08-concierge
cp .env.example .env
```

```
TG_API_ID=1234567
TG_API_HASH=abcdef0123456789abcdef0123456789
```

`.env` в git не попадает. Никому эти значения не пересылай: вместе с доступом к номеру
они дают вход в аккаунт.

### 3. Разовый вход

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python concierge.py login
```

Telegram спросит номер, пришлёт код в приложение, при двухфакторке — пароль. Всё
вводится в терминале.

После входа появится `session/concierge.session`. Это ключ от аккаунта: кто им владеет,
тот пишет от твоего имени. Файл в gitignore — не коммить его и не пересылай в
мессенджерах. Больше входить не придётся.

### Ключ модели не нужен

Anthropic, OpenAI и любые другие ключи этому модулю не нужны и не поддерживаются: тексты
пишет Claude Code. Если что-то просит у тебя ключ модели — это ошибка.

## Кому писать

```bash
cp leads.example.csv leads.csv
```

| Колонка | Что туда |
|---|---|
| `username` | телеграм-ник, с собакой или без. **Обязателен** — писать незнакомым по номеру телефона нельзя |
| `name` | как зовут человека, если знаешь |
| `business` | название и чем занимается |
| `note` | одна строка: что с бизнесом не так |

**`note` — самая важная колонка.** Из неё вырастает первое сообщение. Хорошая заметка:
«сайта нет, только инстаграм, 340 отзывов на картах», «сайт на тильде, цен нет, с
телефона не открывается». Плохая: «стоматология», «возможно интересно».

Пустая заметка — письмо получится безликим, а безликое письмо в холодной переписке не
работает.

Потолок — двадцать строк. Больше скрипт не примет, и это не настройка.

## Что рассказать о себе

Три файла в `knowledge/what-we-offer/`: что предлагаем, чем доказываем, сколько стоит.
Заполни их сам или попроси Claude заполнить по готовому проекту.

Главное доказательство — ссылка на живой сайт, который ты сделал. Не портфолио на десять
экранов, а один пример, который человек откроет за секунду.

Ещё два файла, `knowledge/how-to-write/`, уже написаны: как строится первое сообщение,
что отвечать на «кто вы», «дорого», «у нас уже есть сайт», и чего писать нельзя. Их
менять не нужно.

## Команды

| | |
|---|---|
| `login` | разовый вход в аккаунт |
| `check` | кто подключён, сколько лидов, что в очереди, сколько осталось на сегодня |
| `leads` | список и статусы |
| `queue --to @user --text "…"` | положить письмо в очередь |
| `drain` | показать план; `--confirm` — отправить |
| `inbox` | новые ответы с прошлой проверки |
| `reply --to @user --text "…"` | ответить одному |
| `stop --to @user` | вычеркнуть навсегда |

## Пределы

Заданы в коде, а не в настройках:

- **двадцать лидов** — потолок списка;
- **десять писем за прогон, двадцать в сутки**;
- **паузы 90–300 секунд** со случайным разбросом, длинная пауза пятнадцать минут
  каждые пять писем;
- **два одинаковых текста** в очередь не попадут;
- **повторно тому же человеку** не напишем;
- **«не пишите», «отпишитесь», «спам»** — адресат вычёркивается навсегда;
- **ограничение от Telegram** останавливает весь прогон, а не один адрес.

## Первый прогон

Начни с трёх-четырёх писем, а не с десяти. Посмотри, как отвечают, поправь тон — и
только потом иди на полный список. Так проверяется и текст, и то, как аккаунт переносит
нагрузку.

## Как не потерять аккаунт

Telegram ограничивает аккаунты за сообщения незнакомым. Паузы снижают риск, но не
убирают его. Поэтому:

- пиши с отдельного рабочего аккаунта, а не с личного;
- десять писем в день — потолок, а не цель;
- получил ограничение — остановись на сутки;
- **не переходи на другой номер** — так теряют два аккаунта вместо одного;
- ограничение повторилось — дело не в темпе, а в текстах: они слишком похожи друг на
  друга или слишком похожи на рекламу.
