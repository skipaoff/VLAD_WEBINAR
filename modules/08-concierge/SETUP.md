# Подготовка — до эфира

## 1. Аккаунт

Нужен **отдельный рабочий аккаунт Telegram**, не личный. Живой: с аватаркой, именем,
хоть какой-то историей. Аккаунт, зарегистрированный вчера, получит ограничение на
третьем сообщении.

## 2. Доступ к API

my.telegram.org → API development tools → создать приложение.
Оттуда `TG_API_ID` и `TG_API_HASH`.

```bash
cd modules/08-concierge
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env      # вписать два значения
```

## 3. Авторизация

```bash
.venv/bin/python concierge.py login
```

Telegram спросит номер, пришлёт код в приложение, при двухфакторке — пароль. Всё
вводится в терминале. Появится `session/concierge.session` — это ключ от аккаунта:
он в gitignore, его не пересылают.

## 4. Лиды

```bash
cp leads.example.csv leads.csv
```

Колонки: `username`, `name`, `business`, `note`. Username обязателен — писать незнакомым
по номеру телефона нельзя.

`note` — самая важная колонка. Одна строка про то, что с бизнесом не так: «сайта нет,
340 отзывов», «сайт на тильде, цен нет». Из неё вырастает первое сообщение. Пустая
колонка — сообщение будет никаким.

Потолок двадцать строк, скрипт больше не примет.

## 5. Проверка

```bash
.venv/bin/python concierge.py check
```

Покажет, кто вошёл, сколько лидов, сколько осталось на сегодня.

## Если пришло ограничение

Скрипт остановится сам и напишет об этом. Дальше:

- на сегодня не отправлять ничего с этого аккаунта;
- не пробовать с другого номера — так теряют два аккаунта вместо одного;
- на следующий день начать с трёх-четырёх сообщений, не с десяти.
