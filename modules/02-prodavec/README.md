# Шаг 2. Продавец и видеоконсультант

Один шаг эфира, два решения на одном сайте:

- [videokonsultant](videokonsultant/) — звонок с сайта: лицо, голос, ответы по ценам клиники, запись на приём
- [telegram](telegram/) — продавец в Telegram: кружок-приветствие, SPIN-вопросы, запись и предоплата

Оба берут факты из одной памяти клиники, поэтому не расходятся в ответах.
