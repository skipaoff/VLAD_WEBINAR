# Как определить стек сайта и не гадать

Посмотри в корень проекта сайта и иди по первому совпадению сверху вниз.

| Что видишь | Стек | Рецепт |
|---|---|---|
| `app/` рядом с `next.config.*` | Next.js App Router | [next-app-router.md](next-app-router.md) |
| `pages/` рядом с `next.config.*` | Next.js Pages Router | [next-pages-router.md](next-pages-router.md) |
| `vite.config.*` | Vite (React или без него) | [vite-react.md](vite-react.md) |
| `astro.config.*` | Astro | [static-html.md](static-html.md) |
| просто `index.html`, сборки нет | статика | [static-html.md](static-html.md) |
| ничего из этого | — | [other.md](other.md) |

Хостинг определяется отдельно: если в проекте есть `netlify.toml` — эндпоинт токена берётся
из `token/netlify-function.js`, во всех остальных случаях сайт живёт на Vercel и подходит
вариант из рецепта.

## Что общего у всех рецептов

Три части, и они везде одинаковые:

1. **Виджет** — кнопка на странице. Ядро `voice-widget.core.js` одно на все стеки,
   меняется только способ его подключить.
2. **Стили** — `voice-widget.css` кладётся в публичную папку и подключается один раз.
3. **Эндпоинт токена** — серверная функция, которая выдаёт браузеру короткий пропуск.
   Секреты живут только в ней.

## Проверка после установки, одинаковая везде

```bash
curl -X POST https://САЙТ/api/voice-token
```

- `200` и в ответе `serverUrl` с `token` — эндпоинт стоит правильно;
- `503 voice_not_configured` — не заданы переменные окружения;
- `404` — функция лежит не там, где хостинг её ищет.

Кнопка на странице должна появиться в правом нижнем углу сразу после деплоя. Если она есть,
но соединение висит — дело не в сайте, а в воркере: он либо не запущен, либо у него другое
`agent_name`.
