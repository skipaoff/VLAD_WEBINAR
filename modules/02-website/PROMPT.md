# Промпт для эфира

Работает не как остальные модули: скилл живёт внутри папки, поэтому её нужно открыть
в Claude Code, а не вставлять ссылку в текущий чат.

## Перед эфиром

Открыть в Claude Code папку `modules/02-website`. Проверить, что скилл виден:
он подхватывается из `.claude/skills/stoma-demo`.

## Что вставить в чат

```text
Делаем сайт для клиники https://www.comfort-stom.kiev.ua/, показывай шаги.
```

Всё. Дальше он идёт по десяти шагам сам, после каждого обновляет страницу сборки
справа и спрашивает, двигаться дальше или поправить.

Если у клиники нет сайта — вместо ссылки сказать «сайта нет», и он проведёт по анкете
из `klient/ANKETA.md`.

## Что происходит на экране

1. Справа открывается страница сборки — сначала пустая, с десятью шагами.
2. После каждого шага она обновляется по тому же адресу: видно, что агент нашёл и решил.
3. На четвёртом шаге он спрашивает про ведущую услугу — это единственное решение,
   которое стоит принять вслух, в кадре.
4. На десятом — скриншоты готового сайта.

Ведущему достаточно отвечать «дальше» и один раз выбрать услугу.
