# Промпт для эфира

Работает не как остальные модули: скилл живёт внутри папки, поэтому её нужно открыть
в Claude Code — ссылку в текущий чат вставлять не надо.

## Перед эфиром

Открыть в Claude Code папку `modules/02-website`. Скилл подхватывается из
`.claude/skills/stoma-demo`.

## Что вставить в чат

Два сообщения подряд, в этом порядке.

**Первое — карточка бизнеса с прошлого шага.** Та самая, что копируется кнопкой 01.
Из неё агент возьмёт название, город, услуги, цены и всё остальное.

**Второе — команда на сборку:**

```text
Делаем сайт для бизнеса, карточку которого я вставил выше. Показывай шаги.

Есть действующий сайт — я дам ссылку, тогда данные бери с него.
Нет ни карточки, ни сайта — проведи меня по анкете из klient/ANKETA.md
и не выдумывай ничего сверх моих ответов.
```

Дальше он идёт по десяти шагам сам, после каждого обновляет страницу сборки справа
и спрашивает, двигаться дальше или поправить.

## Почему именно так

Бизнес выбирается один раз, на первом шаге, и дальше все шаги работают с ним. Если
назвать бизнес заново здесь, легко получить сайт не для того клиента, о котором шла
речь минуту назад, — в эфире это заметят.

## Что происходит на экране

1. Справа открывается страница сборки — сначала пустая, с десятью шагами.
2. После каждого шага она обновляется по тому же адресу: видно, что агент нашёл и решил.
3. На четвёртом шаге он спрашивает про ведущую услугу — это единственное решение,
   которое стоит принять вслух, в кадре.
4. На десятом — скриншоты готового сайта.

Ведущему достаточно отвечать «дальше» и один раз выбрать услугу.
