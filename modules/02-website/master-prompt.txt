## Шаг 8. Обязательная самопроверка перед показом

- В глобальный CSS добавь button { color: inherit; appearance: none; } — иначе Safari красит текст кнопок синим
- На секциях с якорями scroll-margin-top под фиксированную шапку
- В узких карточках не задавай переносы жёсткими <br/>: длинные украинские слова должны переноситься сами (break-words + hyphens-auto), иначе на планшетной ширине карточки обрежутся
- Проверь горизонтальное переполнение программно на ширинах 360, 390, 414, 768, 1024, 1280: ни один элемент не должен вылезать за правый край
- Проверь, что нет белого текста на светлых участках фото; где фон непредсказуем, ставь тёмную полупрозрачную подложку под текст
- Пройди все клики: меню, лого, карточки, чипы, фото, кнопки — мёртвых элементов быть не должно
- npm run build должен проходить без ошибок
