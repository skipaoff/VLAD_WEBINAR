# Модуль 02 — сайт

Мастер-промпт, который уже проверен вживую: по нему собран сайт стоматологии Comfort на
Троещине. Промпт лежит целиком в [master-prompt.txt](master-prompt.txt) — его копирует кнопка
на пульте, и он же является источником истины. Правки вносятся здесь, а не в пульте.

## Что он делает

Восемь шагов, каждый обязателен:

1. Вытаскивает данные со старого сайта клиента — услуги, цены, врачей, гарантии.
2. Скачивает и отбирает фотографии, отбрасывая мусорные кадры.
3. Берёт дизайн-паттерн `health-portal` из MotionSites MCP — он написан под стоматологию.
4. Заменяет тексты паттерна на данные клиента, дословно по списку.
5. Достраивает секции: живые фото, врачи, честные цены, футер.
6. Делает шесть внутренних страниц услуг на hash-роутинге.
7. Добавляет модалку записи и плавающие кнопки мессенджеров.
8. Прогоняет самопроверку: переполнение на шести ширинах, мёртвые клики, сборка.

## Почему он такой длинный

Потому что проверен. Каждый пункт восьмого шага — это баг, который уже случался: Safari
красит текст кнопок синим, длинные украинские слова рвут карточки на планшете, белый текст
пропадает на светлом фото. Короткий промпт даёт красивый скриншот и десять мелких поломок,
которые видно в эфире.

## Что менять под другой бизнес

Промпт привязан к конкретному клиенту в четырёх местах:

| Блок | Что в нём клиентского |
|---|---|
| Клиент | название, город, ссылка на старый сайт |
| Шаг 1, ключевые факты | телефон, адрес, имена врачей, вилка цен — по ним агент проверяет, что всё нашёл |
| Шаг 2 | имена файлов фотографий |
| Шаг 4 | все тексты сайта дословно |

Остальное — шаги 3, 5, 6, 7, 8 — переносится на любую стоматологию без правок.

Блок «ключевые факты» выбрасывать нельзя. Он работает как контрольная сумма: агент сверяет
с ним то, что вытащил, и не идёт дальше, если чего-то не нашёл. Без него на выходе получается
сайт с половиной прайса.
