# Сайт клиники по шагам

Собирает сайт стоматологии и показывает работу по ходу: после каждого шага справа
открывается страница с тем, что уже сделано — ДНК клиники, аудитория, конкуренты, оффер,
структура, сборка, страницы услуг, самопроверка. После каждого шага останавливается и
спрашивает: идём дальше или что-то поправить.

Ничего не выдумывается. На странице только то, что реально нашли на сайте клиники или
получили от неё в анкете.

## Почему это работает в эфире

Обычная сборка выглядит как десять минут молчания и стена текста в конце. Здесь зритель
видит десять понятных шагов, и на каждом — что именно агент узнал и решил. Плюс на
четвёртом шаге вопрос задаётся вслух: ведущая услуга это решение, а не факт, и его
принимают вместе.

## Как запустить

1. Открой в Claude Code **папку этого модуля** — скилл живёт внутри неё, в `.claude/`.
2. Вставь карточку бизнеса, с которым работаешь: название, город, услуги, цены.
3. Напиши: «делаем сайт для бизнеса, карточку которого я вставил выше, показывай шаги».

Бизнес выбирается один раз и дальше не меняется. Если назвать его заново на этом шаге,
легко собрать сайт не тому клиенту, о котором шла речь.

Есть действующий сайт клиники — дай ссылку, данные возьмутся с него. Нет ни карточки,
ни сайта — агент проведёт по анкете `klient/ANKETA.md` вопросами.

Страница сборки открывается в панели артефактов справа. Не открылась сама — вызывается
сочетанием `ctrl+]` или командой `/artifacts`; ссылку Claude даёт в чате.

Панель артефактов недоступна — в `запасной-путь/` лежит то же самое обычным окном
браузера.

## Что внутри

```
.claude/skills/stoma-demo/
  SKILL.md         сам скилл: цикл «шаг — показ — вопрос»
  PATTERN.md       дизайн-паттерн целиком, внешние коннекторы не нужны
  artifact.py      собирает страницу сборки из состояния прогона
assets/            картинки паттерна, скролл-герой и видео к нему
klient/ANKETA.md   анкета, если сайта у клиники нет
klient/foto/       сюда фотографии клиники
запасной-путь/     то же самое окном в браузере
```

## Фотографии

На сайт попадают только фото из `klient/foto/`. Чужие лица ставить нельзя, даже временно.
Нет фото врачей — блок команды собирается без портретов.
