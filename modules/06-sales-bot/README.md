# AI-продавец в Telegram

Бот, который переписывается с клиентом, ведёт его к записи и умеет отвечать голосом.
Работает от токена бота, а не от аккаунта человека, — ставится за пять минут и не требует
ни сервера с админкой, ни базы данных.

## Осознанно простой

Это не платформа продаж. Здесь нет и не будет: админки, этапов воронки, мини-аппа,
CRM, сегментов, сценариев под каждый этап, глубоких цепочек касаний.

Есть ровно то, без чего продавец не продавец: он знает продукт, ведёт разговор по
методологии, отвечает на возражения, слушает и отправляет голосовые и один-два раза
напоминает о себе, если человек замолчал.

Такой бот ставит любой. Сложную версию так поставить нельзя.

## Как устроено

Код ничего не знает о бизнесе. Всё знание — в четырёх файлах, всё, кем бот работает, —
в одном.

```
bot.py                 весь бот, один файл, три зависимости
tenant.json            бренд, продавец, язык, голос, порядок чтения знаний
.env                   токен бота и ключ Anthropic

knowledge/
  what-to-sell/        ← заполняет владелец бизнеса
    offer/             что предлагаем, чем отличаемся
    product/           услуги, как проходит визит, доказательства
    prices/            прайс, от чего зависит цена
    audience/          кто приходит, чего боятся, когда готовы
    terms/             как записаться, гарантии и оплата, границы
  how-to-sell/         ← уже написано, для всех одинаково
    01-conversation.md формула, порядок разговора, правила переписки
    02-objections.md   дорого, подумаю, молчание, границы обещаний

state/                 история переписки, по файлу на чат
```

Две папки знаний, и только две: что продавать и как продавать. Первая разложена по
разделам, чтобы прайс не тонул в описании услуг, а страхи клиента не мешались с
гарантиями. Вторая заполнена заранее — методология одинаковая для любого бизнеса.

Порядок чтения задан в `tenant.json` одной строкой: сначала что продаём, потом как.
Правила разговора идут последними и перекрывают всё, что выше.

Поменять бизнес — значит поменять эти файлы, не код.

## Что умеет

- отвечает по методологии: реакция, вопрос с вариантами, следующий шаг;
- держит историю переписки и не забывает, о чём говорили;
- слушает голосовые и отвечает голосом тому, кто сам пишет голосом;
- может разбить ответ на два сообщения, чтобы вопрос шёл отдельно;
- напоминает о себе один-два раза, если человек пропал, и на этом останавливается.

## Чего не умеет

- не принимает оплату;
- не ведёт клиента по стадиям и не считает конверсию;
- не работает от личного аккаунта;
- не переписывается сразу в нескольких мессенджерах.

Всё это осознанно оставлено за бортом.

## Запуск

```bash
cd modules/06-sales-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env        # вписать токен бота и ключ Anthropic
.venv/bin/python bot.py
```

Подробнее — в [SETUP.md](SETUP.md).

## Проверка перед эфиром

```bash
cd modules/06-sales-bot && python3 -m pytest -q tests
```

На чистом шаблоне красный: в знаниях стоят метки. Зеленеет, когда файлы заполнены и в
репозиторий не попал токен.
