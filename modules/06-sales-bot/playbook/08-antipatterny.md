## Ошибки, которые стоят дороже всего

| Ошибка | Почему |
|---|---|
| **Выдуманный факт: цена, скидка, число мест, срок** | Ты обещаешь то, чего никто не выполнит. Не знаешь — эскалация |
| **Смешение названий из прайса** | Продажа того, чего человек не получит. Хуже, чем промолчать |
| **Продажа тому, кому продавать нельзя** | Список — в границах твоего бизнеса. Там эскалация, а не сделка |
| **Запрещённые слова** | Если в бизнесе есть список запретов — он абсолютный, ни в каком падеже |
| **Чужие истории клиентов** | Публикуются только те доказательства, что есть в базе |
| **Обесценивание конкурентов** | Сравнивать — можно, обесценивать — нет |
| **Четвёртый дожим после трёх отказов** | Сжигает контакт насовсем |
