# Промпт для эфира

Ведущий копирует это кнопкой на пульте и вставляет в тот же чат, где делали сайт.

```text
Отлично. Последнее — посадим на этот бизнес AI-продавца в Telegram,
чтобы он переписывался с клиентами и доводил их до записи.

Готовое решение лежит здесь:
https://github.com/skipaoff/VLAD_WEBINAR/tree/main/modules/06-sales-bot

Забери репозиторий, открой modules/06-sales-bot/CLAUDE.md и делай
строго по нему. Коротко, что там:

1. Попроси у меня токен бота от @BotFather и ключ Anthropic.
   Я положу их в .env, в чат писать не буду.

2. Собери данные о бизнесе. Услуги, цены, адрес, часы и тон бери
   с сайта, который мы только что сделали. Если чего-то нет —
   спроси одним сообщением и жди, не выдумывай.

3. Разложи это по папке knowledge/what-to-sell: offer, product,
   prices, audience, terms. Прайс перенеси целиком — продавцу
   запрещено называть числа, которых там нет.
   Папку how-to-sell не трогай, там методология продаж.

4. Заполни tenant.json: бренд, имя продавца, язык, куда слать
   заявки. Если нужен голос — id голоса, чей он и какой по
   характеру.

5. Запусти бота: venv, зависимости, python bot.py. Ни туннеля,
   ни вебхука не нужно, он работает long polling'ом.

6. Проверь сам: напиши боту «сколько стоит» и покажи мне ответ.
   Цена должна быть из прайса, а в конце — вопрос.

Ничего не усложняй: там один файл кода на три зависимости, так и надо.
Админку, этапы воронки и базу данных не добавляй.
```

## Что происходит дальше

1. Агент просит два ключа и кладёт их в `.env`.
2. Читает сайт и раскладывает знания по разделам папки what-to-sell.
3. Запускает бота — ни сервера, ни туннеля не нужно.
4. Сам пишет боту и показывает переписку.

Дальше ведущий пишет боту в кадре сам. Если подключён голос — продавец ответит голосовым
на голосовое.
