# Подготовка — до эфира

## 1. Бот

Написать @BotFather, `/newbot`, придумать имя. Он вернёт токен вида `12345:AA...`.
Это и есть весь доступ: бот работает от себя, аккаунт человека не нужен и не трогается.

## 2. Ключ Anthropic

console.anthropic.com → API Keys. Им бот думает.

Модель по умолчанию — `claude-opus-5`. Если для переписки хочется дешевле, поменяй одну
строку в `.env`: `CLAUDE_MODEL=claude-sonnet-5`.

## 3. Голос (необязательно)

Нужен ключ ElevenLabs — он идёт в `.env` и работает и на расшифровку голосовых клиента,
и на озвучку ответов.

Сам голос настраивается в `tenant.json`, в блоке `voice`:

| Поле | Что вписать |
|---|---|
| `voice_id` | id голоса в ElevenLabs — из библиотеки или свой клонированный |
| `whose_voice` | чей это голос: имя человека |
| `character` | какой он: темп, манера, настроение — одной строкой |
| `model` | `eleven_multilingual_v2` для русского и украинского |
| `settings` | stability, similarity_boost, style, speed |

`whose_voice` и `character` попадают в промпт: бот знает, что его слова будут произнесены
вслух этим голосом, и пишет короче, без списков и скобок.

Настройки по умолчанию — середина: stability 0.5, similarity_boost 0.8. Голос звучит
ровно. Хочется живее — снижай stability до 0.3, но тогда интонация будет гулять между
сообщениями.

Чтобы Telegram показывал ответ как голосовое, а не как файл, нужен `ffmpeg`:

```bash
brew install ffmpeg
```

Пустой ключ или незаполненный `voice_id` — бот работает текстом, ничего не ломается.

## 4. Заполнить знания

Две папки. Владелец заполняет одну.

`knowledge/what-to-sell/` — по разделам: `offer/`, `product/`, `prices/`, `audience/`,
`terms/`. Прайс переносится целиком: продавцу запрещено называть числа, которых там нет.

`knowledge/how-to-sell/` — трогать не надо, там методология. Кроме блока «Роль и манера»
в `01-conversation.md`: туда впиши имя продавца, язык и тон.

Плюс `tenant.json`: название бизнеса, имя продавца, язык, куда слать заявки, голос.

Метки `{{...}}` заменить все до одной. Бот не запустится, если хоть одна осталась, — и это
правильно: иначе он прочитает её клиенту.

## 5. Запуск

```bash
cd modules/06-sales-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python bot.py
```

В консоли появится строка про запуск и включён ли голос. Написать боту `/start` — он ответит.

Чтобы жил после закрытия терминала — держать под `pm2`, `systemd` или в `screen`.
Для эфира достаточно оставить окно открытым.

## Если что-то не так

| Симптом | Причина |
|---|---|
| падает на старте с текстом про метки | не заполнены файлы знаний |
| `KeyError: TELEGRAM_BOT_TOKEN` | нет `.env` или пустая строка токена |
| молчит на сообщения | другой бот с тем же токеном уже запущен где-то ещё |
| голосовые приходят файлом | нет `ffmpeg` |
| отвечает текстом на голосовое | пустые ключи ElevenLabs — это штатно |
