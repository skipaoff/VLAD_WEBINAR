# Подготовка — до эфира

## 1. Выбрать канал

Первое решение, от него зависит, какие ключи просить.

**Бот** — отдельный бот от @BotFather. Ставится за пять минут, аккаунт человека
не трогает, ничем не рискует. Клиент видит пометку «bot» и должен написать боту первым.
Для эфира берут его.

**Живой аккаунт** — продавец пишет от лица человека: имя, аватарка, «был в сети».
Слова «бот» нигде нет. Нужна разовая авторизация по номеру, и аккаунт должен быть
**отдельный рабочий**: продавец отвечает всем, кто пишет в личку.

⚠️ Telegram банит аккаунты за рассылки незнакомым. Продавец там только отвечает тем,
кто написал сам. Холодную базу с него рассылать нельзя.

Сомневаешься — бери бота. Переключиться можно потом одной строкой, знания и переписка
сохранятся:

```json
"channel": "bot"        // или "userbot"
```

## 2. Ключи

Общий на оба канала — **Anthropic**: console.anthropic.com → API Keys. Им продавец думает.
Модель по умолчанию `claude-opus-5`; хочется дешевле для переписки — поменяй одну строку
в `config.json`: `"model": "claude-sonnet-5"`.

**Для канала bot:**

| Что | Где взять |
|---|---|
| `BOT_TOKEN` | @BotFather → `/newbot` → строка вида `12345:AA...` |
| `ADMIN_CHAT_ID` | @userinfobot → ваш числовой id |

`ADMIN_CHAT_ID` — это куда придут новые диалоги, вопросы продавца и пересланные
вложения. Без него продавец работает, но эскалации уходят в лог, а не вам.

**Для канала userbot:**

| Что | Где взять |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | my.telegram.org → API development tools → создать приложение |

Плюс разовая авторизация по номеру — она в шаге 5.

Всё это кладётся в `.env` рядом с `bot.py`, образец в `.env.example`.
⛔ Ключи не диктуются в чат и не пересылаются в мессенджерах.

## 3. Голос (необязательно)

Один ключ **ElevenLabs** закрывает и слух, и голос: им продавец расшифровывает
голосовые клиента и озвучивает свои ответы. Ключ идёт в `.env`.

Сам голос настраивается в `config.json`, в блоке `voice`:

| Поле | Что вписать |
|---|---|
| `enabled` | `true`, чтобы продавец отвечал голосом |
| `voice_id` | id голоса в ElevenLabs — из библиотеки или свой клонированный |
| `whose_voice` | чей это голос: имя человека |
| `character` | какой он: темп, манера, настроение — одной строкой |
| `model` | `eleven_multilingual_v2` для русского и украинского |
| `settings` | stability, similarity_boost, style, speed |

`whose_voice` и `character` попадают в промпт: продавец знает, что его слова произнесут
вслух этим голосом, и пишет короче, без списков и скобок.

Настройки по умолчанию — середина: stability 0.5, similarity_boost 0.8. Голос звучит
ровно. Хочется живее — снижай stability до 0.3, но интонация начнёт гулять между
сообщениями.

Чтобы Telegram показывал ответ голосовым, а не файлом, нужен `ffmpeg`:

```bash
brew install ffmpeg
```

Голосом продавец отвечает только тому, кто сам пишет голосом. Пустой ключ или
незаполненный `voice_id` — работает текстом, ничего не ломается.

Если голосовые нужно понимать, а отвечать голосом нет — ключ ElevenLabs всё равно нужен,
а `voice.enabled` оставь `false`. Запасной вариант расшифровки — OpenAI: положи
`OPENAI_API_KEY` и поставь `"stt": "openai"`.

## 4. Заполнить знания

Две папки, владелец заполняет одну.

```bash
tools/new-business.sh имя-клиента
```

Копия шаблона появится в `business/имя-клиента` — одиннадцать файлов, в каждом написано,
что туда положить. Заполняй в этом порядке, он по важности:

| Очередь | Файл | Почему сначала |
|---|---|---|
| 1 | `03-prices.md` | продавец имеет право называть только эти числа |
| 2 | `10-limits.md` | где он останавливается и зовёт владельца |
| 3 | `07-targets.md` | куда он ведёт человека и по каким шагам |
| 4 | `00-role.md` | как его зовут, на каком языке и в какой манере говорит |
| 5 | `01-offer.md`, `02-product.md` | что продаём и как это устроено |
| 6 | `08-price-play.md` | якоря, дефицит, чем держим цену |
| 7 | `04-audience.md`, `05-terms.md`, `06-voice.md` | кто приходит, условия, слова |
| 8 | `09-phrases.md` | как всё это звучит вслух |

Прайс переноси один в один: неполный прайс превращает разговор в «уточню и вернусь».

`playbook/` **не трогай** — там методология продаж, она написана и одинакова для всех.

Дальше в `config.json`: `"business": "имя-клиента"`.

Метки `{{...}}` заменить все до одной. Продавец не запустится, пока хоть одна осталась, —
и это правильно: иначе он прочитает её клиенту.

## 5. Запуск

```bash
cd modules/06-sales-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

**Живой аккаунт** — сначала разовая авторизация, её делает владелец сам:

```bash
.venv/bin/python tools/login-userbot.py
```

Telegram спросит номер и пришлёт код в приложение. Код вводится здесь, в терминале,
и никуда не пересылается. Файл сессии в `session/` — это ключ от аккаунта, он в
`.gitignore`: не коммить и не пересылай.

Дальше в обоих случаях:

```bash
.venv/bin/python bot.py
```

Ни туннеля, ни белого IP, ни вебхука не нужно. Владельцу придёт сообщение, что продавец
поднялся, и размер знаний.

Чтобы жил после закрытия терминала — держать под `pm2`, `systemd` или в `screen`.
Для эфира достаточно оставить окно открытым.

## 6. Проверить, не трогая клиентов

Владелец пишет боту в личку — а на живом аккаунте в «Избранное»:

```
/asclient сколько стоит
```

Ответ придёт в тот же чат, ни одному клиенту ничего не уйдёт. Смотри три вещи:

1. цена названа из `03-prices.md`, а не выдумана;
2. в конце сообщения есть вопрос;
3. тон совпадает с тем, как говорит бизнес.

Что-то не так — правь файл знаний и жми `/reload`. Перезапуск не нужен, продавец
перечитывает знания на лету.

## Если что-то не так

| Симптом | Причина |
|---|---|
| падает на старте с текстом про метки | не заполнены файлы знаний |
| `Нет ANTHROPIC_API_KEY` | нет `.env` или пустая строка ключа |
| `Канал bot, но в .env нет BOT_TOKEN` | выбран бот, а токен не вписан |
| `Нет сессии seller.session` | канал userbot без авторизации — шаг 5 |
| молчит на сообщения | вторая копия с тем же токеном уже запущена где-то ещё |
| не приходят эскалации | неверный `ADMIN_CHAT_ID` или владелец не писал боту первым |
| голосовые приходят файлом | нет `ffmpeg` |
| отвечает текстом на голосовое | пустой ключ ElevenLabs — это штатно |
| на живом аккаунте отвечает друзьям | аккаунт не рабочий, а личный — так и будет |
