# Шаблон бизнеса

Пустая база знаний продавца. Одиннадцать файлов, в каждом написано, что туда положить.
Копируешь папку под именем клиента, заполняешь метки `{{...}}` — продавец готов.
Методологию в `playbook/` при этом не трогаешь: она уже написана и одинакова для всех.

```bash
tools/new-business.sh имя-клиента
# дальше в config.json: "business": "имя-клиента"
```

Шаблон рассчитан на любой бизнес: офлайн-услугу, онлайн-сервис, курс, агентство,
магазин, частную практику. Поэтому вопросы в файлах заданы нейтрально — «как человек
начинает работу», а не «как записаться на приём». Подставляй свои слова.

## Файлы

| Файл | Что в нём |
|---|---|
| `00-role.md` | кто продавец: имя, бренд, язык, манера, что решает сам |
| `01-offer.md` | что предлагаем, от какой проблемы, чем отличаемся |
| `02-product.md` | из чего состоит, как проходит, доказательства, границы |
| `03-prices.md` | прайс целиком. Чисел, которых здесь нет, не существует |
| `04-audience.md` | кто приходит, чего боится, когда готов |
| `05-terms.md` | как начать, оплата, гарантии, сроки |
| `06-voice.md` | тон и слова: как говорим и как не говорим |
| `07-targets.md` | **вилка:** целевые действия и этапы |
| `08-price-play.md` | **вилка:** якоря, дефицит, удержание цены |
| `09-phrases.md` | **вилка:** живые фразы под этот прайс |
| `10-limits.md` | **вилка:** кому не продаём и что уходит владельцу |

Файлы читаются по номерам. README в промпт не попадает — здесь можно писать заметки
для себя. Нужен свой порядок или лишние файлы — положи рядом `order.txt`, по строке
на файл.

Четыре файла с пометкой «вилка» — места, где универсальная методология встречается
с конкретным бизнесом. Заполнены только они и прайс — продавец уже работает.

## Правила заполнения

- **Прайс переносится целиком.** Продавцу запрещено называть числа, которых в нём нет.
  Неполный прайс превращает разговор в «уточню и вернусь».
- **Чего нет в файлах — того для продавца не существует.** Он не догадывается: он
  ставит эскалацию, и вопрос приходит владельцу в личку.
- **Не оставляй пустых разделов.** Не подходит вашему бизнесу — так и напиши словами:
  «доставки нет», «гарантий не даём», «скидок не бывает». Это тоже ответ, и продавец
  им пользуется.
- Внутренние заметки помечай `## Внутреннее` — продавец их читает, но не пересказывает.
- Абсолютные запреты помечай ⛔, важные оговорки ⚠️.
- Ни одной метки `{{...}}` остаться не должно: продавец не запустится, и это правильно —
  иначе он прочитает метку клиенту.
