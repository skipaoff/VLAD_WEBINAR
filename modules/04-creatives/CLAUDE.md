# Инструкция агенту: собрать креативы из базы

Тебя попросили сделать рекламные креативы и дали ссылку на этот модуль. Здесь лежит готовая база
промптов — по одному файлу на пост. Ничего не сочиняй: твоя работа — показать список, принять
выбор, подставить данные бизнеса и запустить генерацию.

Всё происходит в прямом эфире. Работай быстро и не показывай внутренности.

## Шаг 1. Покажи список и жди выбора

Возьми таблицу из `README.md` нужной ниши и выведи её одним сообщением: номер, название, что
получится на выходе. Ничего не добавляй от себя.

Скажи одной строкой: «назови четыре-шесть номеров». И жди. Не начинай генерировать раньше.

Если ниша бизнеса не совпадает ни с одной папкой в `prompts/` — скажи об этом прямо и предложи
ближайшую по духу, а не выдумывай новые промпты на ходу.

## Шаг 2. Собери данные

Всё берётся из контекста — сайт, который делали до этого, уже открыт в этом же чате. Спрашивай
только то, чего там нет.

| Что | Откуда |
|---|---|
| название бренда | с сайта |
| язык надписи | язык сайта; если сомневаешься — спроси одной строкой |
| имена врачей и специальности | спроси, только если выбраны посты 09 или 10 |
| фирменный цвет | с сайта, если он там есть |

## Шаг 3. Подставь

В каждом выбранном промпте:

1. `{{BRAND}}` — название бизнеса как есть, без перевода.
2. `{{DOCTOR NAME}}` — имя врача, до трёх строк, на языке бизнеса.
3. **Язык надписи.** По умолчанию английский — он уже вписан в промпт. Если язык бизнеса другой,
   возьми готовую строку из таблицы внизу файла и замени ею английскую. Для языка, которого в
   таблице нет, переведи сам и держи длину строк примерно той же.
4. **Цвет.** Промпты написаны под сине-белую палитру — это стиль ниши, и в ленте они смотрятся
   как один набор. Меняй цвет только если у бизнеса есть свой фирменный: тогда замени слова
   `blue` и `cyan-blue` на нужный оттенок во всём промпте разом, иначе получится каша.

Готовый текст каждого промпта сохрани отдельным файлом: `creatives/NN.prompt.txt`.

## Шаг 4. Запусти генерацию

Все выбранные посты запускай сразу, не по очереди — иначе ведущий будет ждать в кадре.

```bash
mkdir -p creatives
# по одному на каждый выбранный номер, без --wait: команда сразу вернёт id задачи
higgsfield generate create nano_banana_pro \
  --prompt "$(cat creatives/06.prompt.txt)" \
  --aspect-ratio 4:5 --resolution 2k
```

Собери id всех задач и дождись их:

```bash
higgsfield generate wait <job_id> --interval 5s
```

Модель — `nano_banana_pro`: она держит 4:5 и лучше остальных рисует текст. Не подменяй её на
`gpt_image_2` — у него нет 4:5.

Скачай результаты в `creatives/` с понятными именами: `06-veneers-facts.png`.

## Шаг 5. Покажи

Одним сообщением: превью всех картинок и под каждой — номер и название поста. Без отчёта о том,
как ты это делал.

Если какая-то картинка вышла плохо — текст поехал, руки кривые, лицо странное — скажи об этом
сам и предложи перезапустить именно её. Не жди, пока заметят в кадре.

## Чего не делать

- Не переписывай промпты «чтобы лучше». Они собраны так, что дают один узнаваемый стиль ленты;
  правка одного промпта ломает набор.
- Не добавляй в промпт логотип, если его нет в файле, и не выдумывай слоганы.
- Не генерируй больше, чем попросили: каждая картинка стоит денег.
- Не пиши на картинке цены и телефоны — они устаревают, а пост остаётся.
