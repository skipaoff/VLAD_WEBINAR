# Промпт для эфира

Это то, что ведущий копирует кнопкой на пульте и вставляет в Claude Code — в тот же чат, где
делали сайт. Агент сам покажет список постов, ведущий назовёт номера голосом.

```text
Сайт есть. Теперь сделаем клиенту контент — рекламные креативы под его нишу.

База: https://github.com/skipaoff/VLAD_WEBINAR/tree/main/modules/04-creatives

Забери репозиторий, открой modules/04-creatives/CLAUDE.md и делай по нему.
Коротко, что там:

1. Покажи мне таблицу постов из базы: номер, название, что получится на
   выходе. Ничего не добавляй от себя.

2. Дождись, пока я назову четыре-шесть номеров. Пока не назвал — ничего
   не генерируй.

3. Подставь в выбранные промпты данные бизнеса: название бренда, язык
   надписи, имена врачей если они нужны. Бери с сайта, который мы только
   что сделали, спрашивай только то, чего там нет. Текст на картинке по
   умолчанию английский, готовая строка на другом языке лежит внизу
   каждого промпта.

4. Запусти все выбранные разом, не по очереди: higgsfield, модель
   nano_banana_pro, флаг --aspect-ratio 9:16. Флаг обязателен — без него
   выйдет квадрат, даже если в промпте написано иначе.

5. Скачай результат в creatives/ и покажи превью одним сообщением: под
   каждой картинкой номер и название поста.

Промпты не переписывай — они собраны так, чтобы лента выглядела одним
набором. Вышло криво — скажи сам и перезапусти именно этот пост.
```

## Что происходит дальше

1. Агент выводит таблицу из десяти постов с подписями.
2. Ведущий вслух выбирает четыре-шесть номеров.
3. Агент подставляет бренд и язык, запускает генерацию параллельно.
4. Через пару минут показывает готовые картинки в формате Instagram.

Одна картинка в 2k — 2 кредита Higgsfield. Пять постов на эфир обойдутся в 10 кредитов.
