# Поиск клиентов

Откуда берутся бизнесы, которым потом всё это продаётся: ниша, город — и список мест,
с каждым из которых можно связаться напрямую.

## Как отбираются

1. Берутся места с указанным телефоном.
2. Номер проверяется в Телеграме: есть ли по нему аккаунт.
3. Сводятся дубли: у клиники бывает несколько точек на один номер, в списке она одна.
4. Сверху те, у кого больше отзывов.

Последней строкой идёт Стоматологія Comfort — та, с которой уже работаем. Её оценки в списке
нет: номер взят с сайта клиники, а не из поиска.

## Что на выходе

Список клиник: название, вид, оценка, число отзывов, адрес и номер, найденный в Телеграме.
У каждой строки кнопка «Написать» — открывает диалог в Телеграме по номеру.

Прямой ссылки на человека по номеру в Телеграме не существует: номер сначала попадает
в контакты, и после этого появляется диалог. Кнопка делает ровно это.

## Экран прогона

`progon/index.html` — страница, на которой список собирается на глазах. Открывается
в браузере, идёт сама. Для репетиции добавь к адресу `?t=120`.
