# Скилл переехал

С 29.09.2026 скилл «Бизнес под ключ» живёт своим репозиторием, чтобы его можно
было отдавать людям одной ссылкой:

**https://github.com/skipaoff/biznes-pod-klyuch**

Там же лежат страницы результата (ролик и объявление) и вся инструкция.
Поставить:

```
mkdir -p ~/.claude/skills && curl -sL https://github.com/skipaoff/biznes-pod-klyuch/archive/refs/heads/main.tar.gz | tar -xz -C ~/.claude/skills && mv ~/.claude/skills/biznes-pod-klyuch-main ~/.claude/skills/biznes-pod-klyuch
```

Прежняя копия скилла осталась в истории этого репозитория — коммит `091ec78`.
