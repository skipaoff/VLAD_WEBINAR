# VLAD_WEBINAR

Заготовки модулей под живое демо на вебинаре. Каждый модуль — готовое решение, которое
агент ставит на сайт клиента одной командой. Внутри модулей нет ни ключей, ни данных
конкретного бизнеса: они заполняются в эфире, после трёх вопросов ведущему.

| № | Шаг | Модуль | Статус |
|---|---|---|---|
| 01 | Собрать инфу про клиента | — | вне репозитория |
| 02 | Собрать сайт по шагам | [02-website](modules/02-website/) | готов |
| 03 | Прикрепить голосового ассистента | [03-voice-assistant](modules/03-voice-assistant/) | готов |
| 04 | Сделать креативы | [04-creatives](modules/04-creatives/) | готов |
| 05 | Запустить рекламу | [05-ads](modules/05-ads/) | готов |
| 06 | Подключить AI-продавца | [06-sales-bot](modules/06-sales-bot/) | готов |
| 07 | Написать лидам | [07-concierge](modules/07-concierge/) | готов |
| 08 | Платформа поиска клиентов | [app.worknothunt.xyz](https://app.worknothunt.xyz) | по желанию |

Первый шаг — данные бизнеса — живёт вне этого репозитория.

Порядок шагов не случайный. Сначала показывается, что агенты делают работу на уровне эксперта:
сайт, ассистент, креативы, реклама, продавец. И только потом, когда в это уже поверили, —
переход на платформу и ответ, откуда брать клиентов. Этот вопрос не должен перебивать показ
работы: заданный раньше времени, он ломает весь поток.

Седьмой шаг закрывает круг: тем же самым, что собрали одному клиенту, консьерж пишет
сразу десятерым. Восьмой стоит отдельно и не обязателен — это ответ тем, кто спросит,
где брать лидов в количестве.

Модули устроены по-разному, и это намеренно. Голосовой ассистент и продавец — рабочий код,
который заполняется под бизнес. База креативов — не код, а библиотека промптов: ведущий
выбирает из готового списка. Реклама — база знаний плюс прямые вызовы API.

Общее у всех одно: код ничего не знает о бизнесе. Знание живёт в отдельных файлах, и
поменять бизнес значит поменять файлы, а не код.

## Как этим пользуются

Ведущий копирует промпт с пульта и вставляет в Claude Code. В промпте — ссылка на нужный
модуль. Агент забирает модуль, задаёт три вопроса про бизнес, заполняет шаблоны и ставит
модуль на сайт. Ключи ведущий не диктует и не показывает: они уже лежат в `.env` на машине.

## Правило репозитория

Секретов здесь нет и не будет. Каждый модуль хранит только `.env.example` с пустыми полями.
